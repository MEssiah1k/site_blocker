Site Blocker
============

一个 Edge 浏览器扩展，用于拦截指定网站并提供高摩擦力的临时访问机制。核心思路：不追求绝对防绕过，而是让绕过的过程足够繁琐，使你在操作期间冲动消退。


安装
----

1. Edge 地址栏输入 `edge://extensions/`
2. 打开"开发人员模式"
3. 点"加载解压缩的扩展"，选择本扩展的文件夹
4. 工具栏出现图标，安装完成


快速上手
--------

**第一步：添加规则**

点击工具栏图标打开弹窗，输入域名（如 `youtube.com`），选择拦截等级，点"保存"。

也可以点击"添加当前网站"按钮，自动填入你正在浏览的网站域名。

**第二步：被拦截时申请访问**

当你访问被拦截的网站时，浏览器不会打开原页面，而是跳转到拦截页。根据网站等级，你可以申请一段时间的临时访问。

**第三步：管理规则**

弹窗中默认只能查看和添加规则。点击"解锁管理"并通过验证码后，才能编辑、删除或切换规则开关。


拦截等级
--------

### 等级 0 · 完全禁止

- 永久拦截，无法申请临时访问
- 被拦页面只显示"该网站已被永久禁止"，没有任何申请入口
- 适用于你确定完全不想再碰的网站

### 等级 1 · 受控使用

- 可以申请 5 ~ 30 分钟的临时访问
- 验证码长度随申请时长线性增长：5 分钟对应 20 字符，30 分钟对应 50 字符
- 申请越久，要手动输入的字符越多，适合有时确实需要用、但不想随便打开的网站

### 等级 2 · 偶尔使用

- 可以申请 5 ~ 120 分钟的临时访问
- 验证码比等级 1 短：5 分钟对应 10 字符，120 分钟对应 50 字符
- 适合不是完全不能用、但不想天天泡在里面的网站

> 以上是默认配置。你可以通过"自定义配置"功能修改等级数量、参数和公式，详见下方。


临时访问申请
------------

当你访问被拦截的网站时：

1. 拦截页显示申请表单，**默认已为最短时长生成验证码**，你可以直接开始输入
2. 修改申请分钟数后，页面实时预览所需验证码长度
3. 点击"生成验证码"（或修改时长后自动触发），系统生成一串随机字符
4. 手动输入验证码，确认后跳转到原网站
5. 临时访问到期后，后台自动清除授权并刷新所有该域名的标签页，重新拦截

> 如果你还没输入完验证码就改了申请时长，需要重新生成验证码。


规则管理
--------

### 查看规则

弹窗中显示所有规则列表，每条规则显示域名、等级标签、备注。有临时访问的规则会显示实时倒计时（MM:SS 格式，每秒更新）。

### 解锁管理

点击"解锁管理"按钮，系统会生成一道变换题：给定一串字母，你需要对每个字母**翻转大小写，再在字母表中后移 2 位**。

例如：给定 `aKz`，你需要输入 `CMb`（a→翻转→A→+2→C，K→翻转→k→+2→m→大写→M，z→翻转→Z→+2→B→小写→b）。

输入错误后自动换一道新题。解锁状态仅在当前弹窗会话有效，关闭重开需重新解锁。

### 编辑和删除

解锁后，每条规则旁出现操作按钮：

- **开关**：切换启用/禁用，禁用后不再拦截该域名
- **编辑**：修改域名、等级、备注
- **删除**：需确认，同时清除该域名的临时访问记录

### 一键添加当前网站

点击"添加当前网站"按钮，自动从当前标签页提取域名并填入输入框，省去手动输入。

### 域名输入自动规范化

输入域名时，扩展自动去除 `https://`、`www.`、路径等无关部分，并在输入框下方实时预览规范化后的结果。例如输入 `https://www.youtube.com/watch?v=xxx`，预览显示"将保存为：youtube.com"。

### 重复域名检测

添加已存在的域名时，扩展会提示"该域名已存在"，防止重复添加。


自定义配置
----------

扩展支持通过 JSON 配置文件自定义所有行为参数，包括拦截等级数量、验证码时长公式、字符集等。

### 打开配置页面

三种方式：
- 弹窗底部点击"高级配置"链接
- 右键扩展图标，选择"选项"
- Edge 扩展管理页点击"扩展选项"

### 编辑配置

配置页面提供一个 JSON 文本编辑器。你可以直接修改 JSON 内容，支持的操作：

| 按钮 | 功能 |
|------|------|
| **验证** | 检查配置格式和逻辑正确性，不保存 |
| **保存** | 先验证再保存，校验失败则阻止保存 |
| **重置默认** | 恢复默认配置到编辑器（不自动保存，需手动点保存） |
| **导入文件** | 从本地 .json 文件加载配置到编辑器 |
| **导出文件** | 将当前编辑器内容下载为 .json 文件 |
| **预览公式** | 查看各等级验证码长度随申请时长的变化 |

### 配置文件结构

```json
{
  "version": 1,
  "minRequestMinutes": 5,
  "maxCaptchaLength": 100,
  "captchaChars": {
    "upper": "ABCDEFGHIJKLMNOPQRSTUVWXYZ",
    "lower": "abcdefghijklmnopqrstuvwxyz",
    "digits": "0123456789",
    "symbols": "!@#$%^&*()"
  },
  "levels": {
    "0": { "label": "完全禁止", "allowTempAccess": false },
    "1": {
      "label": "受控使用",
      "allowTempAccess": true,
      "maxMinutes": 30,
      "captchaFormula": { "type": "linear", "minLength": 20, "maxLength": 50 }
    },
    "2": {
      "label": "偶尔使用",
      "allowTempAccess": true,
      "maxMinutes": 120,
      "captchaFormula": { "type": "stepped", "baseLength": 5, "baseMinutes": 5, "stepMinutes": 10, "stepLength": 5 }
    }
  }
}
```

### 可配置项说明

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `minRequestMinutes` | 最短可申请时长（分钟） | 5 |
| `maxCaptchaLength` | 验证码最大长度 | 100 |
| `captchaChars` | 验证码字符集（upper/lower/digits/symbols，symbols 可为空） | 标准字符集 |
| `levels` | 等级定义，key 为非负整数 | 0/1/2 三个等级 |

每个等级的 `color` 字段可选，用于自定义等级标签颜色（如 `"#e74c3c"`），不填则自动生成。

### 验证码公式类型

**linear（线性插值）**

验证码长度在 `minLength` 和 `maxLength` 之间线性插值。适合验证码难度均匀递增的场景。

```json
{ "type": "linear", "minLength": 20, "maxLength": 50 }
```

**stepped（阶梯增长）**

每经过 `stepMinutes` 分钟，长度增加 `stepLength` 个字符。适合难度跳跃式增长的场景。

```json
{ "type": "stepped", "baseLength": 5, "baseMinutes": 5, "stepMinutes": 10, "stepLength": 5 }
```

**expression（自定义表达式）**

用数学表达式定义公式，变量 `T` 代表申请分钟数。支持 `+` `-` `*` `/` `%` 运算符和 `floor()` `ceil()` `round()` `min()` `max()` 函数。

```json
{ "type": "expression", "expression": "5 + 5 * floor((T - 5) / 2)" }
```

### 添加自定义等级

在 `levels` 中添加新的 key 即可，例如：

```json
"3": {
  "label": "低限制",
  "allowTempAccess": true,
  "maxMinutes": 240,
  "captchaFormula": { "type": "expression", "expression": "3 + ceil(T / 30)" }
}
```

保存后，弹窗的等级选择下拉框会自动显示新等级。

### 公式预览

在配置页面点击"预览公式"，选择一个等级后可输入申请时长查看验证码长度，或查看表格预览各时长对应的验证码长度。建议在保存前使用预览确认公式行为符合预期。

### 校验机制

保存前必须通过校验，校验内容包括：

- JSON 格式和字段类型正确
- 字符集无重复字符
- 等级参数范围合法（maxMinutes >= minRequestMinutes 等）
- 自定义表达式语法正确且能在边界值处正常计算
- 公式计算结果不超过 maxCaptchaLength
- 现有规则引用的等级在新配置中仍然存在（否则阻止保存）

校验失败时显示具体错误信息，校验通过但有潜在问题时显示警告。


防绕过措施
----------

- 验证码输入框**禁止粘贴、拖放、自动补全、拼写检查**——必须逐字手打
- 验证码显示区域**禁止文本选择**，无法复制
- 尝试粘贴时显示红色提示"验证码必须手动输入，禁止粘贴"
- 验证码使用 `crypto.getRandomValues()` 生成，保证密码学级别的随机性
- 申请临时访问的验证码长度与请求时长挂钩，无法通过短验证码获得长时间访问
- 管理操作需要先通过独立的变换验证码解锁
- 解锁验证码输入错误后自动换一道新题
- 每次打开弹窗都需要重新解锁，权限不保留
- 拦截页刷新后验证码状态重置，需要重新申请


数据持久化
----------

- 所有数据存储在 `chrome.storage.local`，包括规则列表、临时访问记录、配置
- 浏览器关闭重启后数据仍然保留
- 浏览器启动时自动清理过期的临时访问记录，并为仍有效的记录重新注册定时器
- 扩展首次安装时自动初始化默认配置和空数据


常见问题
--------

**Q: 扩展能防止我卸载它吗？**

不能。这是浏览器的限制，任何扩展都可以被用户手动禁用或卸载。本产品的定位是自律辅助工具，不是强制监管软件。

**Q: 我能修改某个等级的最大申请时长吗？**

可以。在配置页面修改对应等级的 `maxMinutes` 即可。

**Q: 我能自定义验证码的字符集吗？**

可以。修改 `captchaChars` 中的 `upper`、`lower`、`digits`、`symbols` 字段。`symbols` 可以为空字符串，其他三项必须非空且无重复字符。

**Q: 我删除了一个等级，但已有规则引用了它怎么办？**

校验时会阻止保存，提示你先修改或删除引用该等级的规则。

**Q: 临时访问到期时我正在页面内会怎样？**

扩展不会强制关闭你的标签页，但刷新或跳转时会重新拦截。下一次导航到该域名时会被拦住。
