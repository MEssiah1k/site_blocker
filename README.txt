Site Blocker
============

一个 Edge 浏览器扩展，用于拦截指定网站并提供高摩擦力的临时访问机制。核心思路：不追求绝对防绕过，而是让绕过的过程足够繁琐，使你在操作期间冲动消退。


功能
----

### 拦截规则

- 添加域名到拦截列表，设定等级后，每次访问该域名都会被拦住并跳转到扩展内部页面
- 域名匹配包含子域名：拦截 `youtube.com` 会同时拦截 `www.youtube.com`、`m.youtube.com` 等
- 输入域名时自动规范化：去除协议头（`https://`）、`www.` 前缀、路径、端口，实时预览规范化结果
- 可一键添加当前标签页的域名
- 每条规则可附加备注（如"视频网站"）
- 规则支持启用/禁用开关，禁用后不再拦截

### 三个等级

**等级 0 · 完全禁止**
- 永久拦截，无法申请临时访问
- 被拦页面只显示"该网站已被永久禁止"，没有任何申请入口

**等级 1 · 受控使用**
- 可以申请 5 ~ 30 分钟的临时访问
- 验证码长度随申请时长线性增长：5 分钟对应 20 字符，30 分钟对应 50 字符
- 申请越久，要手动输入的字符越多

**等级 2 · 偶尔使用**
- 可以申请 5 ~ 120 分钟的临时访问
- 验证码比等级 1 短：5 分钟对应 10 字符，120 分钟对应 50 字符
- 适合不是完全不能用、但不想天天泡在里面的网站

### 临时访问申请流程

1. 访问被拦截的网站时，页面显示申请表单
2. 输入想要使用的分钟数，实时预览所需验证码长度
3. 点击"生成验证码"，系统生成一串随机字符（包含大小写字母、数字、符号）
4. 手动输入验证码，确认后跳转到原网站
5. 临时访问到期后，后台自动清除授权并刷新所有该域名的标签页，重新拦截

### 防绕过措施

- 验证码输入框禁止粘贴、拖放、自动补全、拼写检查——必须逐字手打
- 验证码显示区域禁止文本选择（`user-select: none`）
- 验证码使用 `crypto.getRandomValues()` 生成，保证密码学级别的随机性
- 申请临时访问的验证码长度与请求时长挂钩，无法通过短验证码获得长时间访问
- 管理操作（编辑、删除、开关规则）需要先通过独立的验证码解锁
- 解锁验证码要求对每个字母做变换（翻转大小写 + 字母表后移 2 位），比普通验证码更费脑
- 解锁验证码同样禁止粘贴，输入错误后自动换一道新题
- 每次打开弹窗都需要重新解锁，权限不保留

### 规则管理

- 弹窗中查看所有规则列表，显示域名、等级标签、备注
- 有临时访问的规则会显示倒计时（MM:SS 格式，每秒更新）
- 点击"解锁管理"通过验证码后，可以：
  - 切换规则的启用/禁用开关
  - 编辑规则的域名、等级、备注
  - 删除规则（需确认，同时清除该域名的临时访问记录）

### 数据持久化

- 所有数据存储在 `chrome.storage.local`，包括规则列表、临时访问记录、设置
- 浏览器启动时自动清理过期的临时访问记录，并为仍有效的记录重新注册定时器
- 扩展首次安装时自动初始化存储


安装
----

1. Edge 地址栏输入 `edge://extensions/`
2. 打开"开发人员模式"
3. 点"加载解压缩的扩展"，选择本扩展的文件夹
4. 工具栏出现图标，安装完成


使用方法
--------

**添加拦截规则**

点击工具栏图标打开弹窗，输入域名（如 `youtube.com`），选择等级，保存。也可以点击"添加当前网站"一键填入当前标签页的域名。

**申请临时访问**

访问被拦截的网站时，页面显示申请表单。输入想使用的时长，生成验证码，手动输入后确认跳转。到期后自动重新拦截。

**管理规则**

弹窗中默认只能查看和添加规则。点击"解锁管理"并通过验证码后，才能编辑、删除或切换规则开关。


技术说明
--------

- 基于 Manifest V3，使用 `chrome.webNavigation.onBeforeNavigate` 拦截导航
- 仅拦截主框架导航（`frameId === 0`），不影响 iframe 和子资源
- 临时访问到期使用 `chrome.alarms` API 定时触发，到期后自动刷新相关标签页
- 弹窗通过 `chrome.storage.onChanged` 监听存储变化，实时反映其他上下文（如被拦页面授予临时访问）的更新
