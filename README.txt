Site Blocker — 自律网站拦截器
==============================

一款帮助你抵抗诱惑、养成专注习惯的 Edge 浏览器扩展。
当你试图访问"浪费时间"的网站时，它会拦截页面，强制你冷静思考后才能继续。


核心功能
--------

1. 三级拦截策略

   等级 0 · 完全禁止
     彻底拦截，没有任何临时访问入口。适用于你下定决心永不再碰的网站。

   等级 1 · 受控使用
     可以申请临时访问（5 ~ 30 分钟），但需要手动输入一串随机验证码。
     验证码长度随申请时长线性增长——想用越久，输入越多字符。

   等级 2 · 偶尔使用
     同样支持临时访问（5 ~ 120 分钟），验证码更短，适合偶尔需要但不想沉迷的网站。

2. 验证码防作弊

   - 所有输入框禁止粘贴，必须逐字手打
   - 拦截页验证码：纯复制即可，但字符数足以让你冷静
   - 管理权限验证码：需要对每个字母做大小写翻转 + 字母表后移 2 位转换
     例如显示 aHj，需输入 CjL

3. 临时访问倒计时

   - 拦截页申请成功后自动跳转到目标网站
   - Popup 中实时显示剩余可用时间
   - 时间耗尽后自动刷新页面，重新进入拦截状态

4. 规则管理保护

   - 默认状态下只能查看规则和添加新规则
   - 编辑、删除、开关规则需要先通过验证码解锁管理权限
   - 权限在本次打开插件期间有效

5. 快捷添加

   - Popup 内置"添加当前网站"按钮，一键提取当前标签页域名并填入表单


安装方法
--------

1. 打开 Edge，地址栏输入 edge://extensions/
2. 开启"开发人员模式"
3. 点击"加载解压缩的扩展"
4. 选择本扩展所在的文件夹
5. 安装完成，工具栏会出现 Site Blocker 图标


使用说明
--------

添加规则
  点击工具栏图标 → 在"域名"栏输入要拦截的域名（如 youtube.com）
  → 选择拦截等级 → 点"保存"。
  也可以点"添加当前网站"按钮，自动填入当前页面域名。

申请临时访问（等级 1 / 2）
  被拦截的页面会显示申请表单 → 输入需要的时长 → 系统自动生成验证码
  → 手动输入验证码 → 点确认，跳转到目标网站。

解锁管理权限
  在 Popup 的规则列表区点"解锁管理" → 按规则转换验证码 → 输入后确认。
  解锁后可编辑、删除、开关任意规则。


文件结构
--------

  manifest.json              扩展配置
  src/
    background/
      service-worker.js       后台服务：导航拦截、定时器、过期刷新
    lib/
      constants.js            常量定义
      captcha.js              验证码生成与转换
      domain.js               域名规范化与匹配
      rule-engine.js          拦截判断引擎
      storage.js              数据读写
    pages/
      popup/                  Popup 界面
      blocked/                拦截页界面
