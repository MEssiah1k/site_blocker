Site Blocker
============

又刷了一小时短视频？

打开 YouTube "就看五分钟"，一抬头天黑了。说好不碰微博，手指比脑子诚实。

Site Blocker 不会帮你下定决心——但它能让你每次动摇时，都不得不停下来想一想。


它是怎么工作的
--------------

你把容易沉迷的网站加进拦截列表，设一个等级。之后每次访问这些网站，都会被拦住。

**等级 0 · 完全禁止**
碰都不想再碰的网站。没有临时访问，没有商量余地。

**等级 1 · 受控使用**
有时候确实需要用，但不能放飞。可以申请 5 ~ 30 分钟的临时访问，但你要手动输入一串验证码——想用越久，要打的字符越多。在你一个一个敲的时候，冲动可能就过去了。

**等级 2 · 偶尔使用**
不是完全不行，就是不想天天泡在里面。可以申请 5 ~ 120 分钟，验证码比等级 1 短，但依然要手打。


为什么不是简单屏蔽
------------------

简单的屏蔽墙太脆弱——你随时可以关掉扩展、删掉规则、一秒破功。

Site Blocker 的设计思路是：**让你绕过的成本高到懒得绕**。

- 验证码必须手动输入，禁止粘贴——复制粘贴没有冷静效果
- 管理规则（编辑、删除、开关）需要先通过更难的验证码解锁
- 临时访问时间到了自动刷新页面，把你踢出去
- 哪怕你现在冲动解锁了管理权限，下次打开插件还得再来一遍


怎么用
------

**安装**

  1. Edge 地址栏输入 edge://extensions/
  2. 打开"开发人员模式"
  3. 点"加载解压缩的扩展"，选这个文件夹
  4. 工具栏出现图标，装好了

**添加拦截规则**

  点工具栏图标，输入域名（比如 youtube.com），选等级，保存。或者直接点"添加当前网站"，一键填入你正在看的页面。

**申请临时访问**

  被拦住时页面会显示申请表。输入想用多久，系统生成验证码，手打进去，确认跳转。时间到了自动回来。

**管理规则**

  默认只能看和加。要点"解锁管理"，通过验证码拿到权限，才能编辑、删除、开关规则。


一句话总结
----------

它不是锁——它是你和冲动之间那几秒钟的距离。
